## Problem and outcome

**Where it fits.** ORC-029 r12 has each part of the design show where it stands in the factory, with evidence. That only stays true if Orchestrator notices changes it did not make.

- **Collaborators use their own tools** (Claude Code, Cursor, by hand).
- **The vision stays local:** it is neither shared nor written into the repository.
- **So sync must come entirely from git.**

**Outcome: drift detection.**

- Whenever commits land on the main branch, from anyone, Orchestrator re-derives the as-is state of the parts those commits touched, with ORC-032's machinery, read-only.
- It compares that with the locked vision.
- Where they differ, the part shows "drifted", with the evidence. For example: "the invite sheet no longer matches its design", with the built screen beside the prototype.
- The owner chooses, at the cost of one decision:
  - **take it into the vision:** a design decision someone made in code, which becomes a draft to lock in;
  - **restore the design:** the factory gets the work.
- The same comparison supplies ORC-029 r12's "built and verified" status.

**Outcome: bugs as mismatches, fixed at the root.** A bug is the product doing something other than what was intended, which is the same mismatch the project exists to close. The Bug fix flow gains three steps:

1. **Show the bug on the design surface:** expected against actual, at the part of the design it violates.
2. **Classify where the mismatch started:**
   - **intent never captured:** the vision gains the decision;
   - **case left undecided in the design:** a new row in the table of cases and outcomes, which is also the source of special-casing in code;
   - **built wrong against a right design:** the fix, plus a check or test the factory now runs;
   - **a check or review that should have caught it:** tighten the review criteria, principles or automated checks.
3. **Close that gap as well as fix the code,** so the class of bug cannot return (principles: fix root causes; encode lessons in structure).

**For Orchestrator itself,** the same root-cause practice applies in ORC-030's stabilization pass.
